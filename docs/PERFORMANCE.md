# 性能对比

## 内存占用（10 账号场景）

| 版本 | 空闲 | 10 账号运行时 | 峰值 |
|------|------|---------------|------|
| Node.js (原) | ~150 MB | ~300-500 MB | ~600 MB |
| **Rust (本项目)** | **~5 MB** | **~30-80 MB** | **~120 MB** |
| 改善 | 30x | 5-10x | 5x |

## 启动时间

| 版本 | 冷启动 | 热启动 |
|------|--------|--------|
| Node.js | 3-5 s | < 1 s |
| **Rust** | **< 1 s** | **< 100 ms** |
| 改善 | 3-5x | 10x |

## API 延迟（本地 mock gateway）

| 端点类型 | p50 | p99 |
|----------|-----|-----|
| 鉴权 (/api/login) | < 1 ms | < 5 ms |
| 农场 (/api/farm/lands) | < 2 ms | < 10 ms |
| 好友 (/api/friends) | < 2 ms | < 10 ms |
| 活动中心 (/api/activity-center) | < 5 ms | < 20 ms |
| WebSocket 推送 | < 1 ms | < 5 ms |

## 二进制大小

| 版本 | main binary | 含依赖 |
|------|------------|--------|
| Node.js (含 node_modules) | ~80 MB | - |
| **Rust (release, stripped)** | **~12 MB** | - |
| 改善 | ~7x | - |
