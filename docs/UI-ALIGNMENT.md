## 工作约定

- 每完成一个模块：跑 `cargo test --features ui-preview`（全量）→ 重渲染预览 → 本文件打勾。
- 主题（light/dark）、150% 缩放、最小窗口（1100×720）三套都要核对。
- GPUI 特有且合理的部分（如界面偏好 tab）不删除，只对齐布局语言。
